## Scientific conventions and interoperability limits

No undocumented departure from the repository's scientific contract was confirmed. The
following intentional limits remain relevant to downstream use:

- **Return and mutation model:** Parsing returns DataFrames; association attaches
  metadata in place and returns `None`. It does not construct a StationXML Inventory or
  infer an ObsPy Response from a link. Source rows and comments remain available through
  the GeoCSV attachment and its metadata.
- **Timezone and precision:** Parsing preserves supplied zones and leaves naive
  timestamps naive. Association requires aware event times and compares UTC nanoseconds.
  Tests cover timezone equivalence, fractional precision and tolerance boundaries.
  Pandas datetime storage units may vary; source spelling resolution is retained
  separately.
- **Sampling:** Positive measured rates are preserved. Strict matching uses the
  documented start/count/rate criteria. The explicit anchor fallback requires a unique
  containing segment and complete clipped sample coverage, counting overlap once;
  half-sample ties and excessive grid drift raise. Masked gaps and ambiguity raise
  deliberate errors. No resampling or interpolation is performed. Grid coverage does not
  reconstruct upstream sample contributions or prove physical gaplessness after an
  upstream merge.
- **Geography and SAC:** Geographic metadata describe the MERMAID receiver (station).
  Coordinates adopt a documented sea-level elevation of zero. SAC `stdp` is
  approximate station depth in metres positive downward, using
  `WaterPressure / 100` with pressure in mbar (100 mbar approximately 1 m).
  The package supplies only the four station projections `stla`, `stlo`, `stel`,
  and `stdp`; earthquake-source metadata and `ev*` projections are outside scope.
  This approximation uses no equation-of-state conversion. The anchor geography
  convention assumes negligible receiver drift. Missing REQ pressure stays undefined; no pressure
  is borrowed from another row.
- **Persistence and precision:** Arbitrary Stats metadata does not automatically update
  after trim/merge/resampling and is not fully serialized by MiniSEED/SAC. SAC floats
  and samples have float32 storage limits. Complete header equivalence with
  independently produced SAC files is not promised.

## Security and side-effect findings

**Dependency import caveat:** Installed NumPy 2.5.4 temporarily calls `os.putenv` for
`OPENBLAS_MAIN_FREE` during core import, then removes it in a `finally` block. The
inspected installed module, `numpy/_core/__init__.py` (lines 13–21 and 86–88), explains
this as OpenBLAS thread-affinity initialization. The audit probe verified the named C
environment value was restored, as well as unchanged Python environment state. This is
dependency-owned initialization, not package telemetry or a persistent package
environment mutation. A literal guarantee of no environment mutation anywhere in the
dependency stack would be inaccurate.

No hidden telemetry or unauthorized package-owned overwrite was found in the reviewed
source and exercised cases. Hashes in a fetched manifest establish payload integrity
against that manifest, not independent publisher authenticity; the documentation states
this limitation.
